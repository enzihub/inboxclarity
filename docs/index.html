Features

One email instead of forty.

A FastAPI backend reads Gmail and writes the brief. A Next.js app handles sign-in, settings and billing.

Your hour, your time zone

Pick when the brief arrives. The browser's time zone is saved with it and the scheduler converts both to UTC. Unsubscribe from the same card.

Fixed sections, every day

Executive summary, email deadlines, action items, achievements, team updates, blockers and recommendations, from one structured prompt.

Can't wait? Send one now

New users get a button that builds and sends a brief straight away, so nobody waits until tomorrow to see what it does.

Google sign-in through Supabase Auth with the gmail.readonly scope. Expired tokens refresh automatically.
Stripe billing with checkout, customer portal and a webhook that syncs plans into Supabase.
A send queue in Postgres with status, attempts and errors for every brief.
Demo mode that runs the real pipeline on an invented inbox, with no accounts at all.
How it works

From unread mail to one email.

  1. 01 · CONNECTSign in with GoogleSupabase Auth requests only the gmail.readonly scope. Tokens refresh automatically.
  2. 02 · SCHEDULEYour hour, your time zoneEvery five minutes the scheduler queues users whose chosen hour is next.
  3. 03 · SUMMARISERead the last 24 hoursUnread messages go through one structured prompt: deadlines, actions, blockers.
  4. 04 · DELIVERThe Morning BriefA dark HTML email with an AI-written subject line, sent from a tracked queue.
Quick start

Run the demo in two minutes.

No Google, Supabase, AI or email account needed. The backend uses the invented inbox in core/demo/.

git clone https://github.com/enzihub/inboxclarity && cd inboxclarity/core
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
DEMO_MODE=1 .venv/bin/uvicorn main:app --port 8812
# open http://127.0.0.1:8812/demo/brief

# optional: the web app, in two more terminals
cd ../web && npm ci
npm run demo:supabase   # local stand-in for Supabase
npm run demo            # then open http://127.0.0.1:54399/demo/login

For a real setup (Supabase, Google OAuth, Gemini, Mailtrap, Stripe) see the README. Every value in the example env files is blank.
